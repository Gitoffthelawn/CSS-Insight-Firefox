# Store listing copy for 1.24.0

Use the localized summaries in `metadata.json` for AMO. The release notes below are ready for the corresponding localized listing fields.

## English

Release notes:

> Filter Declared Styles, Computed Styles, Media Rules and Keyframes instantly without querying the page again. Complete CSS blocks and enclosing at-rules stay intact, and Copy, Save and View More Details use the visible results.

## Deutsch

Versionshinweise:

> Deklarierte und berechnete Stile, Media-Regeln und Keyframes lassen sich jetzt ohne erneute Seitenabfrage sofort filtern. Vollständige CSS-Blöcke und umgebende At-Regeln bleiben erhalten; Kopieren, Speichern und Weitere Details verwenden die sichtbaren Ergebnisse.

## Español

Notas de la versión:

> Ahora puedes filtrar al instante estilos declarados, estilos calculados, reglas @media y keyframes sin volver a consultar la página. Se conservan los bloques CSS completos y sus reglas contenedoras; Copiar, Guardar y Ver más detalles usan los resultados visibles.

## 日本語

リリースノート:

> ページを再取得せずに、宣言済みスタイル、計算済みスタイル、メディアルール、キーフレームをすぐに絞り込めるようになりました。CSSブロックと外側の@ルールを完全な形で保ち、コピー、保存、詳細表示には表示中の結果が使われます。

## Português do Brasil

Notas da versão:

> Agora é possível filtrar instantaneamente estilos declarados, estilos computados, regras de mídia e keyframes sem consultar a página novamente. Blocos CSS completos e regras externas são preservados; Copiar, Salvar e Ver mais detalhes usam os resultados visíveis.

## Українська

Примітки до випуску:
